copias-pve

copias-pve is a personal backup tool. It copies encrypted backups of a home server to the owner's own Google Drive, so that a copy exists outside the house.

Who uses it

Only its owner, Pedro, on his own Google account. It is not offered to anyone else and has no sign-up.

What it does with Google Drive

  • It asks only for the drive.file permission: it can see and change only the files it created itself, in one folder. It cannot read any other file in the Drive.
  • Everything it uploads is encrypted on the owner's computer before it leaves, with a key that Google never receives. Google stores the encrypted blocks and nothing else.
  • It does not use the data for any other purpose, does not share it, and has no analytics, advertising or tracking.

Privacy policy

Em português: o copias-pve é uma ferramenta pessoal de cópias de segurança. Copia, já cifradas, as cópias de um servidor de casa para o Google Drive do próprio dono. Só pede acesso aos ficheiros que ela própria cria. Política de privacidade.
